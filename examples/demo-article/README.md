# Progetto dimostrativo

Progetto minuscolo per provare subito l'editor:

1. apri questa cartella come progetto ( «Apri cartella progetto» );
2. premi «Compila»;
3. guarda il PDF comparire nel pannello di destra;
4. introduci un errore (es. `\comandonondefinito`) e ricompila per
   vedere l'elenco dei problemi cliccabile.

Contenuto originale, libero da usare e modificare.
